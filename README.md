# 카카오톡 RPG 챗봇 (Cloudflare Workers + D1)

공식 카카오 챗봇 관리자센터(오픈빌더) 스킬 API를 사용하는 RPG 게임입니다. 기존 사용자 ID와 캐릭터 데이터는 D1에 저장됩니다.

## 게임 명령어

| 사용자 발화 | 기능 |
| --- | --- |
| 게임시작 | 캐릭터 생성 및 내정보 |
| 사냥 / 탐험 | 1초 간격 공격, 내가 준 피해량·몬스터 HP·레벨 표시 |
| 내정보 | 레벨·스탯·골드·현재/최대 스태미나 |
| 출석 | 7일차 달성 시 최대 스태미나 영구 +10 |
| 출석현황 | 7일 출석 달성 현황과 보상표 |
| 휴식 | 스태미나 잔량과 다음 자동 회복 시각 |
| 사냥터 | 새로운 몬스터 등장·현재 몬스터 레벨·최대/남은 체력 확인 |
| 스탯 | 미사용 스탯 포인트 확인 |
| 힘 올리기 / 방어 올리기 / 민첩 올리기 | 스탯 1포인트 사용 |
| 랭킹 | 상위 10명 표시 |
| 도움말 | 전체 명령어 |

**사냥 결과**는 스태미나 잔량, 내 공격 피해량, 몬스터 레벨·HP를 보여 줍니다. 기본 최대 스태미나는 **100**입니다. 몬스터 HP는 DB에 저장되며, 처치하면 보상과 함께 다음 스테이지 몬스터가 등장합니다.

### 추천 편의 기능

- **스태미나 자연 회복**: 기본 최대 100(7일 출석 달성마다 영구 +10), **10분마다 +1**. 서버는 사용자가 명령어를 보낼 때 경과 시간을 계산하여 실제 잔량에 반영합니다. 별도의 예약 작업이 필요하지 않습니다.
- **출석 보너스**: 스태미나가 부족할 때 출석으로 보충할 수 있고 골드 보상도 함께 지급합니다.
- **휴식 / 출석현황**: 다음 회복 대기시간 및 연속 출석 상황을 채팅창에서 확인합니다.
- **탐험**: 사냥과 같은 전투 명령어 별칭입니다.

### 7일 연속 출석 보상

| 일차 | 골드 | 스태미나 |
| --- | ---: | ---: |
| 1 | 100G | +3 |
| 2 | 200G | +3 |
| 3 | 300G | +4 |
| 4 | 400G | +4 |
| 5 | 500G | +5 |
| 6 | 700G | +5 |
| 7 | 1,200G | +10 |

- 기준 날짜: **한국시간(Asia/Seoul) 자정 00:00**
- 매일 연속 출석 시 다음 일차로 진행합니다. 하루를 놓치면 1일차로 초기화됩니다.
- 7일차 보상을 받고 다음 날 출석하면 다시 1일차부터 시작합니다.
- 동일 날짜 중복 출석은 보상 없이 안내만 표시합니다.
- 7일차 출석을 완료할 때마다 **최대 스태미나가 영구적으로 +10** 증가합니다(100 → 110 → 120 → 130…).
- 출석 스태미나 보상은 증가한 최대치까지만 적용됩니다. 실제 수령량을 메시지에 표시합니다.

## 필수: 기존 D1에 신규 DB 스키마 적용

기존 서비스가 이미 운영 중이라면 **신규 캐릭터 데이터 초기화 없이** 아래 SQL을 한 번만 적용하세요.

1. Cloudflare → Storage & Databases → D1 → **kakao-rpg-db** → Console 열기
2. [migrations/0002_attendance_stamina.sql](migrations/0002_attendance_stamina.sql) 파일 내용 전체를 Console에 붙여넣고 실행
3. 다음 쿼리로 신규 컬럼 4개 확인

```sql
PRAGMA table_info(players);
```

**중요:** 이 ALTER SQL은 같은 데이터베이스에서 **한 번만** 실행해야 합니다. 기존 users / 스태미나 / 경험치 / 골드는 변경하지 않으며, 새 컬럼만 추가합니다. 실행 전 D1 백업도 권장합니다. DB 업데이트가 아직 안 된 경우 기존 사냥은 작동하지만 출석/자동 회복은 준비 중으로 표시됩니다.

## 카카오 챗봇 블록

카카오 관리자센터 → 시나리오에서 다음 발화를 각각 블록으로 등록하세요.

- 기존: 게임시작, 사냥, 내정보, 스탯, 랭킹 등
- **추가:** 출석, 출석현황, 휴식
- 선택: 탐험 (사냥과 동일한 API 처리)

각 블록은 스킬 **RPG_GAME_API** / 버전 1 선택, 봇 응답은 **스킬데이터 사용**으로 설정합니다. 새 블록 저장 뒤 봇테스트에서 각 발화를 테스트하세요.

**중요:** Workers가 반환하는 quickReplies는 메시지 발화이므로, 블록에 해당 발화가 등록되어 있어야 버튼이 동작합니다.

### 0003 추가 업데이트: 영구 최대 스태미나와 몬스터

위의 0002 스키마를 이미 적용했다면 **다시 실행하지 말고**, [0003_monsters_stamina_capacity.sql](migrations/0003_monsters_stamina_capacity.sql)만 이어서 **한 번** 실행하세요.

0003은 현재 스태미나를 기본 최대 100으로 한 번 채우고, 영구 최대치, 몬스터 종류·레벨·남은/전체 HP 컬럼을 추가합니다. 캐릭터 레벨·경험치·골드 및 출석 기록은 유지됩니다. 기존 7일 출석 달성에는 영구 보너스를 소급 지급하지 않으며, 업데이트 이후 완료하는 7일차부터 적용됩니다.

신규 블록은 `사냥터` 사용자 발화로 만들고, `RPG_GAME_API` 스킬 / `스킬데이터 사용` 응답에 연결하세요. 기존 `사냥`과 `탐험`도 그대로 작동합니다.

**적용 순서:** 0002가 없다면 먼저 0002 → 0003 → Cloudflare 최신 빌드 Ready 확인 → 카카오 `사냥터` / `사냥` / `출석` 테스트. 각 ALTER SQL은 반복해서 실행하면 안 됩니다.
